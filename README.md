# Sec-Repo-by-Data
# Exporting Inventory Data  The script saves sample product data—defined within the code—in three formats:  - `data/Plik_Magazyn.sql` — a script that creates a `magazyn` (inventory) database and a `produkty` (products) table; it also updates an existing product based on its identifier. - `data/Plik_Magazyn.csv` — text-based data in UTF-8 encoding. - `data/Plik_Magazyn.xlsx`
